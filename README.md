# Divyanshu — 1st Birthday Website 🎂
Open `index.html` in a browser (phone par bhi chalega). Pehli screen par "Surprise kholo" dabane se song shuru hota hai.

## Kya-kya hai
- Surprise gate + 9 animated screens, smooth slide/blur transitions
- Tap karne par sparkles, floating balloons, confetti
- Candle-blow cake (cake ya button tap karo)
- Family wishes: Dada ji, Dadi ji, Chachu, Chachi ji, Badi Behen (auto-slide, tap karke next)
- Mumma & Papa ki final wish
- Cute music-box "Happy Birthday" song (built-in)

## Apna song lagana ho?
Koi bhi mp3 `assets/birthday-song.mp3` naam se save kar do — site khud wahi bajayegi. Na ho to built-in music-box song bajta hai.

## Wishes badalni ho?
`index.html` me `class="wcard"` wale blocks me naam (jaise "Chachu" -> "Rohit Chachu") aur text edit kar sakte ho.
